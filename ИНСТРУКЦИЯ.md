# 📱 Android Duo — Полная инструкция пользователя

**Android Duo** превращает ваш Android-планшет (включая Xiaomi Redmi Pad SE) в полноценный второй монитор для Mac с частотой **90 Гц**, минимальной задержкой (**2–5 мс** по кабелю) и поддержкой мультитач-жестов macOS.

---

## ⚡ Режимы работы

| Режим | Кабель Type-C (USB) | Беспроводной (Wi-Fi) |
|---|---|---|
| **Частота экрана** | **90.0 Гц (90 FPS)** | 60.0 Гц (60 FPS) |
| **Задержка** | **2–5 мс** (мгновенный отклик) | 10–25 мс |
| **Зарядка** | Планшет заряжается от Mac | Автономно |
| **Приоритет** | Главный / Максимальное качество | Автоматический резерв |

> 🔄 **Бесшовное переключение:** если отсоединить кабель на ходу, трансляция гладко продолжится по Wi-Fi на 60 FPS. При повторном подключении кабеля система за секунду вернётся на **⚡ USB (90 FPS)** без перезагрузки экрана и мерцания.

---

## 🖥 3 варианта использования на планшете

Вы можете запускать Android Duo на планшете тремя разными способами в зависимости от ваших задач:

| Вариант | Плюсы | Для кого подходит |
|---|---|---|
| **1. Фирменный APK (`Android Duo.apk`)** *(Рекомендуется)* | Без адресных строк, без 3 точек, аппаратное ускорение, автозапуск с Mac | Идеально для ежедневной работы, максимальная производительность |
| **2. Fully Kiosk Browser** | Полная блокировка интерфейса Android (шторки, системных кнопок «Назад/Домой»), строгий режим киоска | Для работы в публичных местах, презентаций или стационарной установки |
| **3. Обычный браузер / Web-PWA (Chrome)** | Работает без установки сторонних APK, подходит для любых планшетов | Если нет возможности установить APK или для быстрого подключения |

## 🛠 Шаг 1. Первоначальная настройка планшета (выполняется 1 раз)

### 1.1. Включение режима разработчика
1. Откройте **Настройки** планшета → **О планшете**.
2. Быстро нажмите **7 раз подряд** на пункт **«Версия ОС»** (или «Версия MIUI / HyperOS»).
3. Внизу появится сообщение: *«Вы стали разработчиком!»*.

### 1.2. Включение отладки по USB
1. Перейдите в: **Настройки → Расширенные настройки → Для разработчиков**.
2. Включите переключатель **«Отладка по USB»** (*USB Debugging*).
3. На предупреждении безопасности подождите таймер 10 секунд и нажмите **«Принять»**.

### 1.3. Фиксация Mac как главного устройства (Host)
> ⚠️ **Критически важно для кабелей Type-C ↔ Type-C:**  
> Чтобы планшет при подключении кабеля не перехватывал роль хоста и не пытался отдавать питание Mac (вызывая сообщение «Медленная зарядка»), нужно зафиксировать его как ведомое устройство:
1. В меню **«Для разработчиков»** пролистайте вниз до блока **«Сети»**.
2. Нажмите **«Конфигурация USB по умолчанию»** (*Default USB configuration*).
3. Выберите **«Передача файлов»** (*File Transfer / MTP*) вместо «Без передачи данных».

### 1.4. Включение 90 Гц в системе планшета
1. Перейдите в: **Настройки → Экран → Частота обновления**.
2. Выберите **Пользовательская → 90 Гц** (чтобы экран планшета работал с максимальной аппаратной плавностью).

---

## 🍏 Шаг 2. Первоначальная настройка Mac (выполняется 1 раз)

1. **Разрешение на запись экрана:**
   - При первом запуске macOS запросит доступ к захвату экрана:  
     **Системные настройки → Конфиденциальность и безопасность → Запись экрана и системного звука** → включите галочку напротив **Android Duo**.
2. **Разрешение на подключение USB-аксессуаров:**
   - **Системные настройки → Конфиденциальность и безопасность → «Разрешать подключение аксессуаров»** → выберите **«Автоматически»** (или нажимайте *«Разрешить»* во всплывающем окне справа вверху при подключении кабеля).

---

## 📦 Шаг 3. Выбор и установка клиента на планшет

### Вариант 1. Фирменный нативный APK (Рекомендуется)
Файл **`Android Duo.apk`** находится в корневой папке проекта.
- **Установка по кабелю с Mac:**
  ```bash
  adb install -r "Android Duo.apk"
  ```
- **Либо вручную:** скопируйте `Android Duo.apk` на планшет и установите через «Проводник».
- В приложении на Mac в меню **Tablet Launch Target** выберите **Native Client**.

---

### Вариант 2. Использование через Fully Kiosk Browser
**Fully Kiosk Browser** позволяет скрыть абсолютно любые системные элементы Xiaomi (включая серую полоску снизу и шторку уведомлений).

1. **Установка Fully Kiosk:**
   - Скачайте и установите **Fully Kiosk Browser** из Google Play или с официального сайта `fully-kiosk.com`.
2. **Первоначальная настройка Fully Kiosk:**
   - Откройте Fully Kiosk на планшете и проведите пальцем от левого края экрана вправо для открытия бокового меню.
   - Зайдите в **Settings**:
     - **Web Content Settings → Start URL:** укажите `http://127.0.0.1:3000/?pwa=1` (для кабеля) или адрес вашего Mac в Wi-Fi `http://192.168.1.X:3000/?pwa=1`.
     - **View Mode:** включите **Fullscreen** (полноэкранный режим).
     - **Kiosk Mode (Plus):** при включении блокирует кнопку «Домой», жесты и шторку уведомлений, превращая планшет в настоящий монитор.
3. **Автозапуск с Mac:**
   - В меню Android Duo на Mac выберите **Tablet Launch Target → Fully Kiosk Browser**.
   - При каждом подключении кабеля Mac автоматически отправит интент запуска в Fully Kiosk с нужным URL.

---

### Вариант 3. Использование через браузер (Chrome / Любой браузер) без установки APK
Если вы не хотите устанавливать APK или подключаете планшет коллеги:

1. **Подключение по Wi-Fi:**
   - Убедитесь, что Mac и планшет подключены к одной сети Wi-Fi.
   - Посмотрите IP-адрес Mac в меню приложения Android Duo (например, `192.168.1.50`).
   - Откройте Google Chrome на планшете и введите:
     ```
     http://192.168.1.50:3000
     ```
2. **Подключение по USB (через браузер):**
   - При подключённом кабеле и включённой отладке по USB введите в браузере:
     ```
     http://127.0.0.1:3000/?pwa=1
     ```
3. **Установка как PWA (Web-приложение на рабочий стол без адресной строки):**
   - В Chrome на планшете нажмите меню (три точки в правом верхнем углу).
   - Выберите **«Добавить на главный экран»** или **«Установить приложение»** (*Install app*).
   - На рабочем столе планшета появится значок **Android Duo**.
   - При открытии с этого значка браузер запустится в чистом окне **без адресной строки и вкладок**.
4. **Полноэкранный режим в браузере:**
   - Нажмите на верхний плавающий индикатор (**Floating Pill**) для вызова панели управления.
   - Нажмите иконку **«На весь экран»** (Fullscreen), либо дважды коснитесь свободного места экрана.

---

## 🚀 Шаг 4. Повседневное использование

### Быстрый старт по кабелю USB (90 Гц, 0 мс)
1. Запустите приложение **Android Duo** на Mac (в строке меню появится иконка планшета).
2. Подключите планшет к Mac кабелем Type-C.
3. На Mac автоматически создастся виртуальный дисплей **Xiaomi Pad SE**, на планшете сам откроется выбранный клиент (нативный, Fully Kiosk или браузер), и экран мгновенно перейдёт в режим **⚡ USB 90 FPS**.

### Быстрый старт по Wi-Fi (60 Гц)
1. Откройте приложение на планшете.
2. Экран автоматически подключится к Mac в режиме **📶 Wi-Fi 60 FPS**.

## 🎛 Сенсорные жесты macOS на экране планшета

- **Перемещение курсора:** плавное скольжение одним пальцем по экрану.
- **Левый клик:** одиночное касание.
- **Правый клик (контекстное меню):** касание двумя пальцами одновременно (или долгое удержание одним пальцем).
- **Скроллинг (прокрутка):** скольжение двумя пальцами вверх/вниз (плавная инерционная прокрутка).
- **Масштабирование (Zoom):** щипок двумя пальцами (Pinch-to-zoom).
- **Перетаскивание (Drag & Drop):** двойное касание с удержанием и ведением.
- **Вызов панели управления планшета:** нажмите на верхний плавающий индикатор (**Floating Pill**), чтобы настроить яркость, переключить режим масштабирования (Fit / Fill) или сменить частоту кадров.

## ⚙️ Настройки в приложении Mac

В окне приложения **Android Duo** на Mac (или кликом по иконке в строке меню):
- **Выбор приложения на планшете (Tablet Launch Target):**
  - **Native Client (По умолчанию)** — быстрое фирменное приложение без адресных строк и рамок.
  - **Fully Kiosk Browser** — открытие через Fully Kiosk (если установлен).
  - **WebAPK / Chrome PWA** — запуск через веб-приложение Chrome.
  - **Standard Browser** — открытие во вкладке браузера по умолчанию.
- **Расположение мониторов:** в меню **Системные настройки → Дисплеи** на Mac вы можете переместить виртуальный экран планшета влево, вправо или выше основного дисплея.

## ❓ Решение частых вопросов (Troubleshooting)

### 1. Кабель подключён, но планшет пишет «Медленная зарядка» и остаётся на Wi-Fi
- **Причина:** Планшет определился как Host (главное устройство) и пытается отдавать питание на Mac.
- **Решение:** Опустите шторку уведомлений на планшете, нажмите на уведомление о зарядке/USB и выберите **«Передача файлов (MTP)»**. Убедитесь, что в меню «Для разработчиков» пункт **«Конфигурация USB по умолчанию»** настроен на *«Передача файлов»*.

### 2. При подключении кабеля планшет спрашивает «Разрешить отладку по USB?»
- Поставьте галочку **«Всегда разрешать с этого компьютера»** и нажмите **«ОК»**.

### 3. Курсор на планшете нажимает со смещением
- В панели управления планшета (нажатие на верхний индикатор) переключите режим масштабирования: **Fit** (по размеру) или **Fill** (заполнение без черных полос). Разрешение виртуального экрана идеально настроено под соотношение сторон 16:10 (1280×800 HiDPI).
