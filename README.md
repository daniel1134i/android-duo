# 📱 Android Duo (macOS Display & Touchpad Companion)

> Превратите ваш Android / Xiaomi / HyperOS планшет в сверхбыстрый сенсорный монитор и тачпад для macOS с частотой до 60 FPS и задержкой менее 25 мс.

## ⚡ Особенности архитектуры

1. **Аппаратный захват экрана через Apple ScreenCaptureKit & Metal GPU**:
   - Минимальная глубина очереди `queueDepth = 1` без буферизации устаревших кадров в macOS (отдаёт строго свежий срез дисплея в реальном времени).
   - Минимальная нагрузка на CPU (~1-2%).
   - Аппаратное сжатие кадров через `CIContext` на GPU Apple Silicon за ~1.5-2 мс.
   - Плавные 60 FPS без задержек буферизации.
2. **Мгновенный транспорт по WebSocket (Binary Frames & TCP_NODELAY)**:
   - Отключение алгоритма Nagle (`TCP_NODELAY`) для мгновенной пересылки каждого байта без сетевой задержки.
   - Паттерн *Drop-Late-Frames* предотвращает накопление сетевой очереди, гарантируя ультранизкую задержку (< 10-15 мс по проводу).
   - Аппаратное декодирование на стороне планшета через `createImageBitmap(blob)` прямо в Canvas.
3. **Нативная эмуляция жестов через macOS CoreGraphics**:
   - Прямой маппинг координат тачскрина (Direct Touch) и относительный режим трекпада (Trackpad).
   - Поддержка одиночных тапов (ЛКМ), долгого нажатия и тапа двумя пальцами (ПКМ), плавного скролла двумя пальцами и перетаскивания (Drag & Drop).
   - Поддержка системных жестов: свайп вверх 3 пальцами (Mission Control), свайп вниз 3 пальцами (Показать рабочий стол).
4. **Оптимизация под Xiaomi Pad и HyperOS**:
   - Полная блокировка стандартных браузерных жестов назад/зума (`touch-action: none`, `overscroll-behavior: none`).
   - Поддержка Screen WakeLock API (экран планшета не засыпает во время работы).
   - Экранная клавиатура и быстрые модификаторы: `Cmd`, `Option`, `Ctrl`, `Shift`, `Enter`, `Esc`, `Cmd+C`, `Cmd+V`.
5. **Два режима подключения и бесшовный Hot-Plug**:
   - 📶 **По Wi-Fi**: мгновенный QR-код в терминале и автоматическое обнаружение IP.
   - ⚡ **По USB-кабелю через ADB**: полное устранение радиопомех Wi-Fi, нулевой пинг и одновременная зарядка планшета.
   - 🔄 **Бесшовный переход**: при отключении кабеля планшет мгновенно переходит на Wi-Fi без обрыва сессии; при повторном подключении кабеля трафик сразу возвращается на USB без открытия новых вкладок браузера.
6. **Интеллектуальный контроль заряда батареи (macOS Style)**:
   - Мониторинг процента заряда Mac и планшета в реальном времени прямо в плавающей плашке (Pill).
   - При заряде батареи ниже 25% выводится элегантное модальное окно в нативном дизайне macOS с кнопкой закрытия.
7. **Аппаратное видео H.264 (Apple VideoToolbox + WebCodecs)**:
   - Сжатие видеопотока через аппаратный чип Apple Silicon (`VTCompressionSession`) в формате NAL-юнитов Annex-B с ключевыми кадрами IDR.
   - Аппаратное декодирование на планшете через HTML5 `VideoDecoder` (WebCodecs API) с экономией трафика в 5–8 раз и автоматическим резервным переключением на JPEG.
8. **Синхронный системный звук с контролем задержки (Audio Sync)**:
   - Захват системного звука macOS через ScreenCaptureKit (48 кГц Stereo PCM).
   - При подключении по USB и минимальной задержке (≤ 15 мс) звук транслируется одновременно на Mac и планшет (`🔊 Mac + Tablet`).
   - При переходе на Wi-Fi или возрастании задержки звук на планшете мгновенно глушится без щелчков, воспроизводясь исключительно через Mac (`🔇 Mac only`).

## 🚀 Быстрый старт

### Требования к системе:
- **Mac**: macOS Monterey 12.3 или новее (Apple Silicon M1/M2/M3/M4 или Intel).
- **Планшет**: Любой Android-планшет (Xiaomi Pad 5/6/7, Samsung Tab и др.) с современным браузером (Chrome, Mi Browser, Kiwi, Firefox).
- **ПО на Mac**: Установленный [Node.js](https://nodejs.org/) (v18+) и компилятор Swift (`xcode-select --install`).

### 1. Установка и сборка

Склонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/your-username/android-duo.git
cd android-duo
npm install
```

> **Примечание**: При `npm install` автоматически скомпилируется нативный Swift-модуль `native/mac_host`. При необходимости ручной сборки выполните:
> ```bash
> npm run build:native
> ```

### 2. Запуск сервера

Вы можете запустить проект любым удобным способом:

#### Вариант А. Через готовый скрипт (Рекомендуется)
Автоматически проверяет сборку, настраивает ADB при подключенном кабеле и запускает сервер:
```bash
cd "/Users/daniel/Documents/android duo"
./start.sh
```
> 💡 **Совет для macOS**: Вы также можете просто дважды кликнуть по файлу `start.command` прямо в Finder!

#### Вариант Б. Через npm / node
```bash
cd "/Users/daniel/Documents/android duo"
npm start
```
*(или напрямую `node server/index.js`)*

Сервер выведет в консоль:
- Список локальных IP-адресов.
- Инструкцию по подключению.
- **Интерактивный QR-код** прямо в терминале для быстрого сканирования камерой планшета!

---

### 3. Остановка сервера

- Чтобы штатно остановить сервер, нажмите **`Ctrl + C`** в окне запущенного Терминала.
- Если необходимо принудительно завершить все фоновые процессы проекта (Node.js сервер и нативный процесс захвата `mac_host`):
  ```bash
  killall -9 node mac_host 2>/dev/null
  ```

## 📱 Подключение планшета

### Вариант А: Беспроводное подключение по Wi-Fi

1. Убедитесь, что Mac и планшет подключены к одной Wi-Fi сети.
2. Откройте камеру на планшете Xiaomi / HyperOS и наведите на QR-код в терминале.
3. Либо откройте Chrome / Mi Browser и введите адрес, показанный в консоли:
   ```text
   http://192.168.1.XXX:3000
   ```
4. Нажмите кнопку **⛶ (Fullscreen)** в выпадающей шторке, чтобы убрать интерфейс браузера.

---

### Вариант Б: Проводное подключение по USB-кабелю через ADB (Рекомендуется для 0 мс задержки!)

Проводное подключение по кабелю USB-C через режим `adb reverse` полностью исключает любые помехи беспроводной сети и обеспечивает максимальный FPS.

#### Шаги настройки:
1. **Включите режим разработчика на планшете**:
   - Откройте *Настройки* -> *О планшете*.
   - Нажмите 7 раз на строку *Версия ОС (HyperOS)* или *Номер сборки*, пока не появится сообщение «Вы стали разработчиком».
   - Перейдите в *Расширенные настройки* -> *Для разработчиков*.
   - Включите тумблер **Отладка по USB** (на устройствах Xiaomi также подтвердите предупреждения безопасности).
2. **Установите ADB на Mac** (если еще не установлен):
   ```bash
   brew install android-platform-tools
   ```
3. **Подключите планшет кабелем к Mac**.
   - На экране планшета появится запрос «Разрешить отладку по USB?». Поставьте галочку «Всегда разрешать с этого компьютера» и нажмите **ОК**.
4. **Пробросьте порт через ADB**:
   ```bash
   adb reverse tcp:3000 tcp:3000
   ```
5. **Откройте браузер на планшете** и перейдите по локальному адресу:
   ```text
   http://localhost:3000
   ```
   *Теперь трафик идет напрямую по проводу USB на максимальной скорости!*

## 🖥 Режим независимого ВТОРОГО монитора (Dual Screen для Xiaomi Pad SE)

В **Android Duo** уже **встроен нативный генератор виртуального дисплея** прямо под разрешение **Xiaomi Pad SE (1920 × 1200, 16:10)**!

Вам **не нужно** вручную устанавливать сторонние утилиты:
1. Запустите скрипт `./start.sh` (или дважды кликните `start.command`).
2. Сервер автоматически создаст в macOS второй независимый экран:
   `[VirtualDisplay] Virtual Display created: Xiaomi Pad SE (1920x1200 @ 60Hz)`.
3. Откройте *Системные настройки macOS* -> *Дисплеи*. Вы увидите второй экран и сможете настроить его расположение (например, справа или слева от экрана ноутбука).
4. Перетаскивайте любые окна программ на планшет — они отображаются на Xiaomi Pad SE в реальном времени, а касания пальцев и стилуса нажимают точно по элементам второго экрана!

*(Опционально: если вы используете BetterDisplay, вы также можете переключать дисплеи прямо из выпадающего списка в веб-интерфейсе планшета).*

## ⚙️ Панель управления на планшете

В верхней части экрана планшета расположена компактная стеклянная «таблетка» (Pill), нажатие на которую открывает панель настроек:
- **Переключатель сенсора**: быстрое включение/отключение тач-ввода (View-Only режим) прямо на компактной плашке `👆 TOUCH: ON` / `🔒 TOUCH: OFF`.
- **Синхронизация яркости**: полная синхронизация с яркостью экрана Mac (клавиши F1/F2 на MacBook или датчик освещенности) + плавный ползунок регулировки яркости прямо в панели.
- **FPS и пинг**: отображение текущей частоты кадров и задержки в миллисекундах.
- **Режим ввода**: переключение между прямым касанием (*Direct Touch*), виртуальным трекпадом (*Trackpad*) и режимом только монитора (*Disabled*).
- **Качество потока**: *Low (40%)*, *Medium (65%)*, *High (85%)* для баланса четкости и пропускной способности.
- **Частота обновления**: выбор 30 FPS или 60 FPS.
- **Экранная клавиатура**: кнопка вызова виртуальной клавиатуры Android для ввода текста в активное окно на Mac.
- **Клавиши быстрого доступа**: `Esc`, `Enter`, `Backspace`, `Space`, `Tab`, `⌘C` (Копировать), `⌘V` (Вставить), `⌘Z` (Отмена).
- **Клавиши-модификаторы**: `⌘ Cmd`, `⌥ Option`, `⌃ Control`, `⇧ Shift` с залипанием для сложных комбинаций клавиш.
- **WakeLock**: предотвращает выключение экрана планшета при отсутствии касаний.

## 🔒 Разрешения macOS (Безопасность)

При первом запуске macOS запросит необходимые системные разрешения:
1. **Запись экрана (Screen Recording)**: требуется для работы `ScreenCaptureKit`.
   - *Системные настройки* -> *Конфиденциальность и безопасность* -> *Запись экрана* -> включите тумблер для вашего Терминала / приложения.
2. **Универсальный доступ (Accessibility)**: требуется для эмуляции кликов и скролла через `CoreGraphics`.
   - *Системные настройки* -> *Конфиденциальность и безопасность* -> *Универсальный доступ* -> разрешите вашему Терминалу.

## 🛠 Устранение неполадок

- **Планшет не открывает страницу по Wi-Fi**:
  Убедитесь, что Mac и планшет находятся в одной подсети и на роутере не включена изоляция клиентов (AP Isolation / Guest Network). В качестве надежной альтернативы используйте проводное подключение через ADB.
- **Черный экран или не передается картинка**:
  Проверьте, выданы ли права на Запись экрана в Системных настройках macOS. Перезапустите сервер после выдачи прав.
- **Курсор не двигается при касании**:
  Проверьте разрешение «Универсальный доступ» (Accessibility) в настройках macOS.
